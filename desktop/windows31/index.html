Read a member site in Windows 3.1

Download the Mosaic launcher and classic gateway (Python source ZIP)

On your modern computer, extract the ZIP. Use Python 3.9 or newer, DOSBox-X with SLIRP, your own installed Windows 3.1 drive, and the Mosaic and Trumpet Winsock archives listed in the included README.

python3 launch-windows31.py switchboard-radio --guest /path/to/drive --media-dir media

Replace switchboard-radio with the YesterSites member name you want to visit. Mosaic opens the live classic edition with its artwork.

Already have a networked DOSBox-X guest?

Run the gateway on the modern host. Open the address below in your guest browser.

python3 legacy_gateway.py switchboard-radio --port 8077
http://10.0.2.2:8077/INDEX.HTM

Use /BBS.HTM for bulletin screens or /TEXT.HTM for text only. Keep the gateway running while you browse. It reads one member site per session.
